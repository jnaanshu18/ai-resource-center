# DCS AI Resource Center — Employee Guide

**Site URL:** https://ai.dailycodesolutions.com/  
**Last updated:** 26 August 2026  

---

## What is this?

The **DCS AI Resource Center** is our internal site for finding AI tools the team already trusts and learning how others use them.

You can:

- Browse **approved AI tools** (Directory)
- Get pointed to the right tool for a job (AI hub + Choose a tool)
- Copy **ready-made prompts**
- Read **team stories** and share your own wins
- **Suggest new tools** for review (Suggestions)

---

## How to sign in

1. Open https://ai.dailycodesolutions.com/
2. Sign in with the **team** username and password shared internally by your admin  
   — or use an **invite link** (`?invite=…`) if you were given one
3. After sign-in you land on **AI hub**

**Do not share login credentials in public channels** (Slack, email to external parties, etc.).

---

## Where to go (site map)

| Tab | What it is | When to use it |
|-----|------------|----------------|
| **AI hub** | Job chooser, Start here, Tool of the week | “I have a task — point me to trusted tools” |
| **Directory** | Full catalog of approved tools | Search, filter, compare, open tool detail |
| **Choose a tool** | Category guides + tool-vs-tool matchups | “Which option in this category?” |
| **Prompts** | Searchable prompt library | Copy prompts for ChatGPT, Claude, Cursor, etc. |
| **Team stories** | Real wins + learning links | See how teammates use tools; share your story |
| **Suggestions** | Tool suggestion queue | Propose a tool the team should evaluate |

**Each sign-in:** AI hub shows a short orientation banner (Directory · Choose a tool · Team stories). Click **Got it** to dismiss for that visit — it returns on your next sign-in.

**Logo / company name** in the header takes you back to **AI hub**.

---

## Directory — what’s in it

Only **approved** tools appear in the Directory:

| Status | Meaning |
|--------|---------|
| **Production** | Core daily tools (e.g. Cursor, OpenClaw) |
| **Approved** | Cleared for team use |
| **Archived** | Kept for reference only |

Tools still being evaluated appear under **Suggestions** (New / In review / Rejected) — **not** in the Directory until an admin approves them.

---

## Tool detail pages

Each approved tool includes:

- Tutorial video + key facts
- When to use / alternatives / team notes
- Limitations, cost & security, DCS evaluation (when available)
- Related **tool-vs-tool** links, **team stories**, and **prompts** (when they match)
- **Visit website** link next to the tool name
- **Add to compare** — pick up to 3 tools for side-by-side comparison in Directory

---

## How to contribute

### Suggest a tool

1. Go to **Suggestions** → suggest form (or Contribute tab)
2. Enter **tool name**, **website URL** (required), and a short note
3. Your suggestion appears in the queue as **New** — an admin will review it

### Share a team win

1. Go to **Team stories** → **Share a win** form
2. Fill in title, tool, impact (max 400 characters), and how you did it
3. After admin approval, your story appears on Team stories

---

## Data safety

- Use only **approved** tools from the Directory for work-related tasks unless your lead says otherwise
- **Never** paste client secrets, personal data (PII), or production credentials into forms or unapproved AI tools
- All directory tools are tagged **Internal** — treat outputs and uploads accordingly

| Issue | What to do |
|-------|------------|

| Suggestion stuck | Ask an admin to review it on the Suggestions tab |
