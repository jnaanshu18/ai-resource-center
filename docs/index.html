How to approve or reject

Admin only — review in GitHub Issues, then update the directory CSV for approvals.

  1. Open a pending item above (or the issue link from someone’s draft).
  2. Approve: add the tool to data/ai_tools_directory.csv with status Approved, push to main, then close the issue.
  3. Reject: close the issue and comment why (duplicate, unsafe, not a fit, etc.). Nothing is added to the directory.
  4. After an approval push, the live site updates and the tool appears under Recently added / Directory for the team to try.
